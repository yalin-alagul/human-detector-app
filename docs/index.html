Human Detector

Sort a photo library by whether people are in it. Detection runs entirely on your Mac. Nothing is deleted, and every run can be undone.

Download for Mac View source

Free for noncommercial use · macOS 14 or later · Apple Silicon only

Three folders, one decision per photo

Point it at a folder of photos. Every image is moved into one of three folders, keeping its sub-folder structure.

clean/

Confident

The detectors agree with high confidence.

review/

Unsure

Borderline scores. A quick look is all it needs, and you can reclassify with a click.

trash/

The other verdict

Still just a move. You delete it yourself, at the end, after spot-checking.

A Goal switch decides what the folders mean. Detection is identical either way.

Built so a wrong guess is cheap

Nothing is deleted

Files are moved, never removed. By default, a name collision gets a suffix instead of an overwrite.

Undo any run

Every move is journalled. Undo Last Run puts the files back where they were.

Private by design

No account and no upload. Your photos never leave the machine. The app goes online only if you choose to download optional models.

Tune it on your photos

Calibrate on a random sample and drag thresholds with instant feedback, before you run the whole library.

Honest about accuracy

No detector is perfect, and this one says so instead of hiding it.

The download runs on Apple Vision only. It detects faces, human outlines and body pose, and it catches fewer people than a dedicated YOLO model, especially small or partly hidden figures.

For best results, add a YOLO model yourself: export one and download it into the app from your own Hugging Face repo, or import it from a folder (the README explains how). Whichever you use, calibrate first and spot-check a random batch of clean/ before deleting anything. If a missed photo would be a real problem, check review/ by hand.

Install

The app is not yet signed with an Apple Developer ID, so macOS asks you to confirm it once.

  1. Download HumanDetector.dmg and open it.
  2. Drag Human Detector into Applications.
  3. Open Applications, right-click the app, choose Open, then Open again. You only need to do this the first time.

If macOS says the app is damaged, clear the download flag in Terminal, then open it again:

xattr -dr com.apple.quarantine "/Applications/Human Detector.app"

Prefer to build it yourself? Clone the repo and run make install.
